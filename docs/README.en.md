All of Vsion's documentation lives here. If you're new, reading the "Getting started" docs in order is enough; look up the rest when you need it.

## Getting started (in order)

| Doc | What it covers | When to read it |
| --- | --- | --- |
| [Models and sign-in](models.en.md) | Adding a model provider, signing in with an account, reasoning effort, models on your own computer or LAN | First thing after installing |
| [Setting up phone control](setup-guide.en.md) | Pairing wireless debugging, accessibility, starting from a computer over USB, step by step | When you want Vsion to operate phone apps; skip it if you only chat, browse and work with files |
| [Ask and Autonomous](modes.en.md) | Which steps Vsion asks you about first in each mode | Before you hand it real work |

Start with [Use Vsion from a computer](computer.en.md): pick CLI + Skill or MCP, and USB or Wi-Fi / VPN. Then follow the matching doc below.

| Doc | What it covers |
| --- | --- |
| [CLI / Skill: install, update and remove](computer-install.en.md) | Installing the `vsion` command or the Skill for your agent |
| [CLI and Skill: connection and task commands](cli.en.md) | Commands to connect to the phone, submit tasks, check progress, answer questions and add instructions |
| [Computer access (MCP)](mcp.en.md) | Letting an MCP client hand tasks to Vsion: USB, Wi-Fi / VPN, tools, security |
